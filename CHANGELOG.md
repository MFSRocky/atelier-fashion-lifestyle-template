# Changelog — ATELIER Website Template

All notable changes to this project are documented in this file in compliance with Semantic Versioning.

## [1.0.0] - 2026-11-18
### Added
- Initial official release of the ATELIER Fashion & Lifestyle Website Template.
- 8 semantic HTML5 page layouts: Home, Collections, Shop, Product, About, Journal, Article, and Contact.
- Modular CSS3 design token system with style.css, components.css, and responsive.css.
- Encapsulated vanilla ES6+ interactions:
  - LocalStorage-persisted cart drawer and wishlist.
  - Multi-criteria catalog filtering and sorting.
  - Image gallery thumbnail switcher with responsive srcset support.
  - Interactive search modal and mobile navigation menu.
  - Client-side form validation with remote endpoint hook (Formspree/Basin/Netlify).
- Bundled offline variable fonts: Playfair Display and DM Sans (SIL OFL 1.1).
- Curated, optimized responsive WebP photography under the Pexels Free License.
- Complete SEO suite: Open Graph tags, Twitter Cards, robots.txt, and sitemap.xml.
- Multi-resolution vector SVG, PNG, and ICO favicon bundle with site.webmanifest.
- Standalone offline HTML help documentation with interactive sidebar navigation.
- Marketplace submission assets: 2340x1560 cover images, screenshots, and listing copy.
- 16-point QA checklist audit passing all accessibility, performance, and validation tests.
