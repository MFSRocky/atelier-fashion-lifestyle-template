2. Quick Start Guide

  1. Extract the archive: Unzip ATELIER-TemplateFlux-v1.0.0.zip on your computer.
  2. Direct Browser Use: You can open template/index.html directly in Chrome, Firefox, Safari, or Edge. No node_modules, npm, or build step is needed.
  3. Local Web Server (Optional): For testing relative routing with standard HTTP origins: 
    # Python 3
cd template && python -m http.server 8080

# Or Node.js
npx serve template
    Then open http://localhost:8080.

4. Central Configuration (site-config.js)

Buyers can customize brand details, contact emails, addresses, and connect backend forms in one single file: template/js/data/site-config.js.

window.SITE_CONFIG = {
  brand: {
    name: 'ATELIER',
    tagline: 'For a life\nwell lived.',
    announcement: 'Complimentary delivery on orders over $250 · A little more room to move'
  },
  contact: {
    email: 'hello@atelier.studio',
    locations: 'Paris · New York · Everywhere'
  },
  // Connect live forms:
  formEndpoint: 'https://formspree.io/f/your_form_id'
};

5. Typography & Offline Fonts

All fonts are locally bundled in template/assets/fonts/ under the SIL Open Font License (OFL):

  • Playfair Display (Headings & Display): Modern transitional serif with high contrast and classic proportion.
  • DM Sans (Interface & Body): Clean geometric sans-serif optimized for legibility across all screen sizes.

No Google Fonts or external network requests are made. The site works completely offline.

6. Design Tokens & Palette

Edit CSS custom properties in template/css/style.css to re-theme the entire website:

:root {
  --ivory: #EAE4D9;      /* Warm neutral surface */
  --cream: #F8F5EF;      /* Primary canvas background */
  --charcoal: #25221F;   /* Primary dark contrast */
  --taupe: #A18B73;      /* Accent tone */
  --taupe-ink: #735D46;  /* High-contrast accent for accessibility */
  --ink-soft: #635D56;   /* Secondary reading typography */
}

7. Connecting Backend Forms

The newsletter and contact forms perform instant client-side validation. To receive live submissions by email, specify your endpoint in template/js/data/site-config.js:

  • Formspree: formEndpoint: 'https://formspree.io/f/xyz'
  • Basin: formEndpoint: 'https://usebasin.com/f/xyz'
  • Netlify Forms: Add data-netlify="true" to the <form> element.

8. Deployment Guide

Deploying to Vercel

# Install Vercel CLI
npm i -g vercel

# Deploy production build
vercel --prod

Deploying to Netlify

Drag and drop the template/ folder directly into Netlify Drop, or push the repository to GitHub and select template as the publish directory.

Deploying to Apache / Nginx / Traditional cPanel

Upload the contents of template/ directly into your server's public_html or web root directory.
