## Item Description (HTML Formatted for ThemeForest)

```html
<p><strong>ATELIER</strong> is an exquisitely designed, editorial website template engineered for independent fashion labels, boutique clothing brands, bespoke design studios, and luxury lifestyle concept stores. Built with clean semantic HTML5, modern modular CSS3, and high-performance vanilla ES6+ JavaScript, ATELIER requires zero build tools, package managers, or framework overhead.</p>

<p>Every layout balances atmospheric editorial storytelling with robust e-commerce UI patterns—including multi-attribute catalog filtering, responsive gallery inspection, color and size selector blocks, local shopping bag state persistence, and client-side form validation hooks ready for instant connection to Formspree, Basin, or Netlify.</p>

<h3>Key Features</h3>
<ul>
  <li><strong>8 Complete Editorial Page Layouts:</strong> Immersive Campaign Home, Seasonal Collections, Filterable Catalog, Product Detail, Brand Story & Values, Field Notes Journal, Editorial Article, and Studio Contact.</li>
  <li><strong>Zero Dependencies & Zero Build Step:</strong> Pure HTML5, CSS3, and ES6+ JavaScript. Open <code>index.html</code> directly or upload to any static hosting provider.</li>
  <li><strong>100% Offline Capable:</strong> Playfair Display and DM Sans variable fonts bundled locally in WOFF2 format under the SIL Open Font License. Zero third-party font or CDN requests.</li>
  <li><strong>Commercial License Verified:</strong> 12 curated Pexels photographs with responsive WebP derivatives legally cleared for commercial redistribution in a template you sell.</li>
  <li><strong>Decoupled Content & Central Config:</strong> Brand tokens, contact details, social links, and form endpoints are easily updated in <code>js/data/site-config.js</code>.</li>
  <li><strong>Interactive Shopping Experience:</strong> LocalStorage-persisted cart drawer, interactive wishlist buttons, real-time category filtering, and multi-mode price/name sorting.</li>
  <li><strong>Multi-Device Responsive Design:</strong> Pixel-perfect fluid layout tested across mobile (375px+), tablet (768px+), and desktop (1440px+).</li>
  <li><strong>Comprehensive Offline Documentation:</strong> Standalone HTML documentation with customization guides, code snippets, and deployment walkthroughs.</li>
  <li><strong>SEO & Social Ready:</strong> Unique meta titles, Open Graph tags, Twitter card tags, favicon multi-resolutions, robots.txt, and sitemap.xml.</li>
</ul>

  <li><strong>Shop (shop.html):</strong> Complete product catalog with real-time category filtering and ascending/descending price sorting.</li>
  <li><strong>Product Detail (product.html):</strong> Multi-angle image gallery with thumbnail switcher, color swatches, size selectors, quantity stepper, accordion specs, and cart drawer.</li>
  <li><strong>Our Story (about.html):</strong> Brand manifesto, core values, atelier worktable photography, and mission statement.</li>
  <li><strong>Field Notes (journal.html):</strong> Editorial publication archive with interactive topic category filtering.</li>
```
